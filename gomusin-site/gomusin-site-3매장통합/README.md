# 심플 검색 — 한솥 레시피 결과물

## 바로 열어 보기
- `index.html` 을 더블클릭하면 브라우저에서 열려요. (설치·빌드 없음)
- 지금은 **가짜 데이터 모드**예요. 입력한 내용은 이 브라우저에만 저장돼요.
- 테스트 계정: `demo@example.com` / `password1234`
- 테스트 쿠폰: `WELCOME10`(10%) · `SAVE3000`(3만원 이상) · `OLD2025`(만료 에러) · `ONCE5000`(이미 사용 에러)
- 에러 화면 보기: 주소 끝에 `?mockError=1` 붙이기 (예: `index.html?mockError=1#/board`)
- 처음 상태로 되돌리기: F12 → Console 에 `API.resetAll()` 입력

## 메뉴
| 주소 | 기능 |
|---|---|
| `#/` | 검색 (디바운스 300ms, 하이라이트, 0건 추천, 최근 검색어 5개) |
| `#/board` | 게시판 (목록·글쓰기·이미지 첨부·수정·삭제·좋아요·공유) |
| `#/shop` → `#/cart` → `#/checkout` | 상품 → 장바구니 → 주문서(쿠폰) → 결제 → 결과 |
| `#/booking` | 달력 예약 |
| `#/store` | 매장 지도·길찾기 |
| `#/contact` | 상담 신청 |
| `#/me` | 마이페이지 (프로필, 내 글, 좋아요, 주문, 예약) |
| 상단 종 아이콘 | 알림 배지·드롭다운 |
